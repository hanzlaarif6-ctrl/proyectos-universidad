# Proyectos universitarios

Selección de prácticas del **Grado en Ingeniería Informática** de la Universitat Rovira i Virgili (URV).

Los repositorios con el código son **privados** porque contienen soluciones de prácticas evaluables. Aquí hay una ficha por proyecto: qué hace, cómo está construido y, en los trabajos de grupo, **qué hice yo**.

> **Código disponible bajo petición.**

| Proyecto | Descripción | Tecnologías | Tipo |
|---|---|---|---|
| [Estructuras de datos en Java](estructuras-datos-java/) | Listas, tablas hash, grafo bipartito genérico y recomendador de artistas. 423 tests JUnit | Java 21, Gradle, JUnit 5 | Individual |
| [Gestor de actividades URV](gestor-actividades-urv/) | Aplicación de escritorio para gestionar actividades, inscripciones y valoraciones, por consola o GUI | Java, Swing, serialización | Grupo de 4 |
| [Arkanoid concurrente](arkanoid-concurrente/) | Juego en terminal convertido, fase a fase, en un programa concurrente | C, POSIX, IPC System V, pthreads | En pareja |
| [Candy Crush para Nintendo DS](candy-crush-nds/) | Juego para NDS con la lógica en ensamblador ARM y gráficos con sprites y fondos | ARM assembly, C, libnds | Grupo de 4 |
| [GarlicOS](garlicos/) | Microkernel multiproceso para Nintendo DS | ARM assembly, C | Grupo de 4 · *en desarrollo* |

Proyecto personal relacionado: [api-gestion-incidencias](https://github.com/hanzlaarif6-ctrl/api-gestion-incidencias), una API REST con Spring Boot, JPA, PostgreSQL y JWT.
